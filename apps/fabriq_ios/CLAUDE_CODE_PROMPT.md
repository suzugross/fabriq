# Claude Code 向け作業依頼テンプレート

以下を Claude Code への最初のプロンプトとして使ってください。
SPEC.md は同階層に置いた状態で実行することを前提とします。

---

## プロンプト本文

Fabriq フレームワーク（PowerShell 5.1 ベースのWindowsキッティング自動化基盤）の上に被せる、Cisco IOS 風コマンドラインシェル `Fabriq IOS` を新規実装します。

これは実用ツールではなく、Fabriqのシュルキティニスム宣言の世界観を体現する**芸術的副産物**として位置付けられる「冗談アプリ」です。ただし以下の3点は真面目に作り込みます：

1. **タブ補完**は本物の Cisco IOS に近い体験
2. **syslog風メッセージ**は Cisco 構文（`*Apr 29 14:23:01.234: %FABRIQ-5-HOSTNAME: ...`）を厳密に守りつつ、内容はシュルレアリスム的な詩
3. **コマンド階層**（User EXEC → Privileged EXEC → Global Config → Interface Config）は IOS を完全に踏襲

詳細仕様は `apps/fabriq_ios/SPEC.md` に記載してあります。まずこれを熟読してください。

### 作業範囲（v0.1）

仕様書の「実装するコマンド（v0.1スコープ）」と「受け入れ基準」セクションを満たす実装を作成してください。

### 重要な制約

- **PowerShell 5.1 互換必須**（PowerShell 7専用機能は使わない）
- **既存のFabriq kernelに変更を加えない**（`apps/fabriq_ios/` 配下のみで完結）
- **Fabriqモジュールの呼び出しは `Invoke-BatchExecution` 経由**で行う（直接コアスクリプトを叩かない）
- **Pesterテスト**を `tests/` 配下に最低限用意する（パーサとモード遷移）
- **日本語コメント**でOK、識別子は英語

### 進め方の希望

1. 最初に SPEC.md を読んで、不明点・設計判断が必要な点を箇条書きで質問してください
2. 質問への回答後、ファイル構成のスケルトン（空ファイル + 主要関数シグネチャ）を提示してください
3. 合意後、実装を順次進めてください
4. 各フェーズで動作確認用の手順も明記してください

### 文化的留意事項

syslog風メッセージのシュルレアリスム文は、ブルトン『シュルレアリスム宣言』とロートレアモン『マルドロールの歌』の文体を参照します。具体的には:

- 機械の擬人化（"The machine sleeps", "The cable dreams of electrons"）
- 異質なものの邂逅（"Address has been whispered to the network adapter"）
- キッティング作業の儀式化（"The name has been carved into silicon"）

ただし**Cisco IOSのsyslog構文だけは厳格に守る**ことが、この冗談の生命線です。詩は構造の中でこそ光ります。

仕様の不明点を質問するところから開始してください。

## 補足: SPEC.md の主要な未確定事項

Claude Code から以下のような質問が来る可能性が高いので、事前に方針を決めておくと進行がスムーズです:

1. **`enable` のパスフレーズ未設定環境での挙動** → デフォルトパスを許容するか、エラーで停止するか
2. **PSReadLine 未インストール環境のフォールバック** → 補完を諦めて素のRead-Hostで動かすか、起動時エラーにするか
3. **エラー系syslogメッセージのCSV化粒度** → 1エラーパターン1行か、テンプレート化してプレースホルダ展開か
4. **`show running-config` の出力フォーマット** → Cisco風に `!` コメント込みか、もっと簡略化するか
5. **`reload` を実装するか** → v0.1では宣言だけ（メッセージ出して終了）か、本当に再起動するか

現時点での推奨方針:

1. デフォルトパス許容しつつ、起動時に警告syslog出力
2. 起動時エラーで停止（PSReadLineは事実上必須依存とする）
3. CSV にテンプレート列を追加してプレースホルダ展開
4. Cisco風（`!` コメント + `hostname xxx` 形式）で芸術性優先
5. v0.1 では宣言だけ（`reload` コマンドで詩的メッセージ出して終了、実際の再起動はしない）
