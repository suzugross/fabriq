■ 概要
winget を使用してアプリケーションを一括管理します。
このモジュールには3つのスクリプトがあります。

[Winget App Installer Update]
  winget 自体（Microsoft.AppInstaller）を最新版に更新します。
  winget_install / winget_upgrade の前に実行することを推奨します。

[Winget App Install]
  app_list.csv に定義されたアプリを winget でインストールします。
  既にインストール済みのアプリはスキップします。

[Winget App Upgrade]
  app_list.csv に定義されたアプリのうち、既にインストール済みの
  ものだけを winget で最新版に更新します。
  未インストールのアプリはスキップします（install 側の責務）。
  既に最新のアプリは Skipped として記録されます。

■ 設定ファイル
[app_list.csv]   ※ install / upgrade で共有
  Enabled     : 有効フラグ（1=実行, 0=スキップ）
  AppID       : winget のパッケージID（例: Google.Chrome）
  Options     : 追加オプション（省略可、install/upgrade 共通）
  Description : 説明（表示用）
  Segment     : セグメント分類（省略可）

[記載例]
  1,Google.Chrome,,Google Chrome,
  1,Adobe.Acrobat.Reader.64-bit,,Adobe Acrobat Reader DC,
  0,Git.Git,--override "/VERYSILENT",Git for Windows,

■ 前提条件
・インターネット接続が必要です（Wait-NetworkReady で自動確認）
・winget (Microsoft.AppInstaller) がインストール済みであること
・winget source が利用可能であること（install/upgrade 前に自動リセット）

■ AutoPilot
AutoPilot モードでは確認をスキップして CSV の設定を自動適用します。
全 3 スクリプト（winget_update / winget_install / winget_upgrade）共通です。

■ AppID の調べ方
コマンドプロンプトで「winget search アプリ名」を実行すると
パッケージIDを確認できます。

■ install と upgrade の振り分け
                        | install | upgrade
  未インストール        | 対象    | スキップ
  インストール済み      | スキップ| 対象
  インストール済み(最新)| スキップ| Skipped (ExitCode -1978335212)

■ 動作の流れ（共通）
1. ネットワーク接続とwingetの利用可否を確認
2. winget source をリセット
3. app_list.csv を読み込み、対象を振り分け
4. 実行確認（Y/N）後、順に install / upgrade を実行
5. 結果を集計して返却

■ ExitCode の扱い (winget_upgrade.ps1)
  0           : 成功
  3010        : 成功（再起動保留）
  -1978335212 : NO_APPLICATIONS_FOUND   → 既に最新として Skipped
  -1978335189 : UPDATE_NOT_APPLICABLE   → 既に最新として Skipped
  その他      : 失敗

■ 冪等性
winget_install:
  winget list --id <AppID> --exact の出力に AppID が現れるか判定し、
  既インストールの場合は Skip します。
winget_upgrade:
  同じ winget list による判定で、未インストールの場合は Skip
  （install 側の責務）。既に最新の場合は ExitCode で Skipped 判定します。
winget_update:
  Microsoft.AppInstaller 自体の upgrade。最新なら ExitCode
  -1978335212 を Skipped として返します。

■ Post-Apply Verification
本モジュールは Post-Apply Verification を実装していません。
install/upgrade 後に winget list での再確認は行わず、ExitCode の
判定結果のみで Success/Failed/Skipped を決定します。
New-BatchResult / New-ModuleResult に -Verified は渡していないため、
実行履歴の Verified 列は空欄になります。
手動での再確認は `winget list --id <AppID>` で行えます。

■ 使用環境変数
本モジュールでは環境変数を参照していません。
