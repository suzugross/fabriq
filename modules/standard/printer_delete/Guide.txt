■ 概要
不要なプリンターを削除します。
3つのモードが共存し、状況に応じて自動で切り替わります。

  [KeepList mode]
    hostlist.csv の Printer1..10Name（選択中ホストの分）と
    printer_driver_config/printer_list.csv の TargetHost マッチ行を
    「残すプリンタ一覧」として解釈し、それ以外の TCP/IP プリンタを
    削除候補にします。
    ※ Windows 組み込みの仮想プリンタ（Microsoft Print to PDF /
      OneNote / Microsoft XPS Document Writer / Fax 等）は
      このモードでは一切削除対象になりません（安全装置）。

  [Explicit mode]
    printer_delete.csv に列挙されたプリンターを名前指定で削除します。
    仮想プリンターも名前一致で削除可能です。
    KeepList と同時にアクティブな場合、Explicit が優先されます。

  [Manual mode]
    どちらのソースも無効な場合のフォールバック。
    GUI で手動選択して削除します（従来動作）。

■ 運用シナリオ（部署展開パターン）
マスタイメージに全部署のネットワークプリンタを一括登録しておき、
PC 展開時に hostlist.csv の Printer1..10Name でその PC が使うプリンタ
だけを宣言しておくと、printer_delete の KeepList mode が自動的に
「宣言されていない他部署のプリンタ」を削除します。

  例: マスタに DeptA-P / DeptB-P / DeptC-P を install
      hostlist.csv の NEW-PC-01 行で Printer1Name=DeptA-P
      → printer_delete 実行で DeptB-P / DeptC-P が削除され DeptA-P のみ残る

PC に詳しくない担当者でも hostlist.csv の編集だけで展開完了できます。

■ 設定ファイル
[printer_delete.csv]（省略可）
  Enabled     : 有効フラグ（1=削除候補, 0=スキップ）
  TargetHost  : 対象ホスト名（空=全ホスト, 値=NewPCName 完全一致）
                ※ 大文字小文字は区別しない
  PrinterName : プリンター名（完全一致）
  Description : 説明（表示用）
  Segment     : プロファイル Segment フィルタ（既存機能、省略可）

[記載例]
  Enabled,TargetHost,PrinterName,Description,Segment
  1,,Fax,全PCでFax削除,
  1,,Microsoft XPS Document Writer,全PCでXPS削除,
  1,NEW-PC-05,OldNetPrinter,このPCだけ古いプリンタ削除,

■ TargetHost 列について（新規）
・空欄の行 → 全ホストで適用（従来の全体共通動作と等価）
・値ありの行 → $env:SELECTED_NEW_PCNAME と完全一致する行のみ採用
・既存の TargetHost 列が無い CSV は「全ホスト扱い」として後方互換動作

■ 仮想プリンタの扱い（重要）
KeepList mode は「PrinterHostAddress を持つ TCP/IP ポートに紐づく
プリンタ」のみを削除候補にします。このため:

  ・Microsoft Print to PDF / OneNote / XPS / Fax 等は、
    KeepList mode では削除されません。
  ・これらを削除したい場合は printer_delete.csv に名前を明記します
    （明示的な意図表明）。
  ・Manual mode では GUI 上に表示されるが pre-check されません。

■ 削除候補の Reason 表記（GUI）
  Keep              : keepNames に含まれ、削除対象外（pre-check なし）
  KeepList          : TCP/IP プリンタで Keep List に無い → 削除候補
  Explicit          : printer_delete.csv の明示指定
  KeepList+Explicit : 両方の条件で削除候補
  (Manual)          : いずれのソースも該当しない（pre-check なし）

■ AutoPilot 対応
AutoPilot モードで実行された場合、GUI は表示されず削除候補が
自動削除されます。削除候補が 0 件の場合は Skipped で終了します。

  ・KeepList が空で候補 0 件 → Skipped（全削除事故を構造的に防止）
  ・Explicit のみで候補あり → その分だけ自動削除
  ・仮想プリンタは依然として保護対象

■ Post-Apply Verification
削除実行後、対象プリンタを Get-Printer で読み返して null 確認し、
New-ModuleResult に -Verified を返却します。

■ 動作の流れ
1. Keep List 収集（hostlist 環境変数 + printer_list.csv TargetHost マッチ）
2. Explicit 削除リスト収集（printer_delete.csv TargetHost マッチ）
3. インストール済みプリンタ列挙 + TCP/IP ポート判定
4. 削除候補計算（Reason 判定付き）
5. AutoPilot → 自動削除、Manual → GUI 表示
6. Post-Apply Verification
7. 結果返却
