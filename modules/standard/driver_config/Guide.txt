■ 概要
PCのサードパーティドライバをエクスポート（バックアップ）およびインポート（復元）するモジュールです。

■ 使い方

[Driver Export]
現在のOSにインストールされているサードパーティドライバを driver/ フォルダにエクスポートします。
エクスポート先: driver/{モデル名}/

[Driver Import]
driver/ フォルダ内のドライバを現在のOSにインポート（インストール）します。
インポート元: driver/{モデル名}/

■ driver.csv の設定

Enabled : 有効フラグ（1=実行, 0=スキップ）
Id      : 識別用の連番
model   : ドライバフォルダ名の明示指定。
          空欄の場合、PCのシステムモデル名を自動取得して使用します。
          （例: Get-CimInstance Win32_ComputerSystem の Model 値）
Segment : セグメント名（任意。空欄=全セグメント共通）
          kernel/common.ps1 の Import-ModuleCsv が共通機構として
          自動フィルタするため、モジュール側に追加実装は不要。

■ スクリプト構成（module.csv）
  driver_export_config.ps1 : 現在の OS からドライバを driver/ 配下に
                             エクスポート
  driver_import_config.ps1 : driver/{model}/ のドライバを pnputil で
                             OS にインポート
  いずれも driver.csv を共有します。

■ モデル名の自動取得
model 列が空欄の場合、以下のコマンドでモデル名を動的取得します:
  Get-CimInstance -ClassName Win32_ComputerSystem | Select-Object -ExpandProperty Model

取得した文字列はフォルダ名として安全に使えるようサニタイズされます:
  - 空白 → アンダースコア
  - ファイル名禁止文字（\/:*?"<>|）→ 除去
  - 80文字上限

■ 使用コマンド
エクスポート: dism.exe /online /export-driver /destination:"<保存先パス>"
インポート:   pnputil.exe /add-driver "<パス>\*.inf" /subdirs /install

※ Export-WindowsDriver PowerShell cmdlet は Windows Server 2022 で
  「SafeHandle を Null にすることはできません」エラーが発生する
  既知の不具合があるため、同一の DismApi を直接呼ぶ dism.exe を
  使用しています。出力フォルダ構造は cmdlet 版と等価です。

■ 注意事項
- 管理者権限が必要です。
- エクスポートはサードパーティドライバのみが対象です（OS標準ドライバは含まれません）。
- エクスポート時、既存のドライバフォルダは中身がクリアされてから再エクスポートされます。
- インポート後に再起動が必要な場合があります（pnputil 終了コード 3010）。

■ 前提条件
- 管理者権限で実行すること（dism.exe / pnputil はいずれも
  管理者権限必須）
- driver/ フォルダ配下にインポート対象モデルのサブフォルダが存在する
  こと（インポート時）
- 十分なディスク空き容量（エクスポート時、元 PC のドライバ容量分）

■ AutoPilot
AutoPilot モードでは確認をスキップして CSV の設定を自動適用します。

■ Post-Apply Verification
本モジュールは厳密な Post-Apply Verification を実装しておらず、
検証は限定的です。
- エクスポート: dism.exe /export-driver 完了後、出力先フォルダの
  *.inf ファイル数をカウントして表示します（0 件ならエラー扱い）。
- インポート: pnputil 実行前後で対象フォルダの *.inf 数を参照し、
  pnputil の終了コード（0/3010 成功）を判定しますが、OS 側に実際に
  組み込まれたドライバのバージョン比較等は行いません。
New-BatchResult に -Verified を渡していないため、実行履歴の Verified
列は空欄になります。必要なら `pnputil /enum-drivers` で手動確認
してください。
