■ 概要
このモジュールには2つのスクリプトがあります。

[Registry Config (HKLM)]
  HKEY_LOCAL_MACHINE にレジストリ値を設定します。

[Registry Delete (HKLM)]
  HKEY_LOCAL_MACHINE のレジストリ値を削除します。

■ 設定ファイル
[reg_hklm_list*.csv]（パターンに一致する全CSVが自動読み込み）
  Enabled      : 有効フラグ（1=実行, 0=スキップ）
  AdminID      : 管理番号（表示用）
  SettingTitle : 設定タイトル（表示用）
  KeyPath      : レジストリパス（フルパス）
  KeyName      : レジストリ値の名前
  Type         : 型（REG_DWORD / REG_SZ / REG_EXPAND_SZ / REG_QWORD / REG_BINARY / REG_MULTI_SZ）
  Value        : 設定する値
  Segment      : Segment フィルタ（省略可）

[記載例]
  1,1,ファイアウォール無効化,HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\SharedAccess\Parameters\FirewallPolicy\DomainProfile,EnableFirewall,REG_DWORD,0

■ ファイル分割
ファイル名が reg_hklm_list*.csv に一致すれば全て読み込まれます。
ジャンルごとにファイルを分けて管理できます。
例: reg_hklm_list.csv, reg_hklm_list_security.csv, reg_hklm_list_ui.csv

■ 前提条件
・管理者権限が必要です
・CSVのエンコーディングは Shift-JIS（ANSI）で保存してください

■ $FORCE_OVERWRITE フラグ（reg_hklm_config.ps1 の先頭で定義）
既定値は $true。全エントリを現在値に関係なく常に上書き適用します。
$false に書き換えると、Test-RegistryValueMatch による冪等性チェックで
既に目標値と一致するエントリは [Skip] として適用をスキップするようになります。
どちらの場合でも Step 5.5（Post-Apply Verification）は常に実行されます。

■ AutoPilot
AutoPilot モードでは確認をスキップして CSV の設定を自動適用します。

■ Post-Apply Verification
本モジュール（Registry Config (HKLM)）は Post-Apply Verification を実装しています。
適用後に Test-RegistryValueMatch で全エントリを再度読み返し、
期待値と一致するか検証します。全件一致時のみ -Verified=$true を
New-BatchResult に渡します。検証失敗が 1 件でもあれば -Verified=$false。
※ Registry Delete (HKLM) (reg_hklm_delete.ps1) 側は Verification を
  実装していないため Verified 列は空欄になります。

■ 動作の流れ
1. reg_hklm_list*.csv を全て読み込み、有効エントリを集約
2. 設定/削除対象を一覧表示（冪等性チェック結果を [Current]/[Change] で表示）
3. 実行確認（Y/N）後、レジストリに書き込み/削除を実行
4. (Config のみ) Step 5.5 で全エントリを読み返して検証
