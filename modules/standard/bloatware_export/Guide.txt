■ 概要
PCにインストールされているデスクトップアプリケーションの一覧をCSVに出力します。
出力されたCSVは bloatware_remove モジュールの入力として使用できます。

■ 出力CSV列
  Enabled      : 有効フラグ（全て0で出力。削除対象は1に変更）
  DisplayName  : アプリ名（レジストリから取得）
  MatchPattern : ワイルドカードパターン（空欄で出力。必要に応じて編集）
  Description  : 表示用ラベル（空欄で出力。必要に応じて編集）
  Segment      : セグメントフィルタ（空欄で出力）
  Publisher    : 発行元（参考情報）
  Version      : バージョン（参考情報）

■ 運用方法
1. bloatware_export を実行してCSVを出力
2. CSVを bloatware_list.csv としてコピー
3. 削除対象の Enabled を 1 に変更
4. 必要に応じて MatchPattern にワイルドカードを設定（例: McAfee*）

■ 前提条件
・管理者権限が必要です（Test-AdminPrivilege で自動チェック）
・HKLM Uninstall レジストリへの読み取り権限
・evidence\inventory\ ディレクトリへの書き込み権限（自動作成）

■ AutoPilot
AutoPilot モードでは確認をスキップして CSV を自動エクスポートします。

■ 出力先
evidence\inventory\app_inventory_日時_PC名.csv

ファイル名のサフィックスに使用される PC 名の優先順：
  1. $env:SELECTED_NEW_PCNAME （Fabriq 実行前に設定された新 PC 名）
  2. $env:COMPUTERNAME         （現在のホスト名にフォールバック）

■ 使用環境変数
  SELECTED_NEW_PCNAME : Fabriq 実行コンテキストで設定される新 PC 名。
                         hostname_config モジュール等で決定された
                         キッティング後のホスト名をファイル名に使用します。
  COMPUTERNAME        : SELECTED_NEW_PCNAME が未設定時のフォールバック。

■ Post-Apply Verification
本モジュールは「出力系」であり、システム状態を変更しません。
Post-Apply Verification は実装していません。
New-ModuleResult に -Verified は渡していないため、
実行履歴の Verified 列は空欄になります。
出力 CSV のファイル生成成否は Status / Message で判定します。

■ 動作の流れ
1. レジストリ（HKLM Uninstall）を64bit/32bitの両方スキャン
2. スキャン対象と出力先を表示
3. 実行確認（Y/N）後、CSVファイルに出力
