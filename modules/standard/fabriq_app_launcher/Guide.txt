■ 概要
Fabriq内蔵アプリ（apps/ ディレクトリ）を起動します。
プロファイル実行中にGUIアプリを挟みたい場合などに使用します。

■ 設定ファイル
[target_apps.csv]
  Enabled     : 有効フラグ（1=実行, 0=スキップ）
  AppName     : apps/ 内のアプリディレクトリ名
  Wait        : 待機制御（1=アプリ終了まで待機, 0=起動後すぐ次へ進む）
  Description : 説明（表示用）
  Segment     : Segment フィルタ（省略可）
                kernel/common.ps1 の Import-ModuleCsv が自動フィルタします。

[記載例]
  1,winget_gui,1,Winget GUI,
  1,storeapp_editor,1,Store App Editor,
  1,local_user_setup,1,Local User Setup,

■ 前提条件
・apps/ ディレクトリが存在すること（モジュール位置の3階層上）
・各アプリが apps/{Name}/{Name}.ps1 の命名規則に従っていること
・powershell.exe が PATH から呼び出せること

■ AutoPilot
AutoPilot モードでは確認をスキップして CSV の設定を自動適用します。

■ 動作の流れ
1. target_apps.csv を読み込み
2. 各アプリを別プロセスとして起動
3. Wait=1 の場合はアプリ終了を待機

■ Post-Apply Verification
本モジュールは「起動系」であり、GUI アプリの起動成否のみを
扱います。Post-Apply Verification は実装していません。
New-BatchResult に -Verified は渡していないため、
実行履歴の Verified 列は空欄になります。

■ 使用環境変数
本モジュールでは環境変数を参照していません。
