[RPA]
初回ログイン時に表示される強制パスワード変更ダイアログを処理します。
operator が「ダイアログが表示されたか」を確認するための Prompt
ステップで一度止まります。OK を押すと続行します。

旧パスワード = $AdminPass、新パスワード = $NewPass を Paste で送信。

実行内容:
  1. Prompt: operator にパスワード変更ダイアログの目視確認を求める
  2. $AdminPass を Paste (旧パスワード欄)
  3. {TAB} で次フィールドへ
  4. $NewPass を Paste (新パスワード欄)
  5. {TAB} で確認用フィールドへ
  6. $NewPass を Paste (確認用パスワード欄)
  7. {ENTER} で送信

[Manual]
パスワード変更画面が表示されない場合 (2 回目以降のログイン等) は、
Prompt で OK を押してそのまま進めて問題ありません (Paste 操作は
別の入力欄に空打ちされるだけ)。

変更完了後、メッセージで成功を確認してから次の Phase へ進みます。
