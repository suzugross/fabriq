[RPA]
P01 で開いた Run ダイアログに "notepad" を入力して Enter を送り、
notepad.exe を起動します。

実行内容:
  1. Run ダイアログにフォーカスを戻す (Pianist のクリックでフォーカスが奪われた直後の復帰)
  2. "notepad" をテキスト入力
  3. Enter を送信
  4. ウィンドウタイトル "メモ帳" が現れるまで最大 8 秒待機

[Manual]
空のメモ帳ウィンドウが起動することを確認します。
タイトルは "無題 - メモ帳" もしくは Win11 新版なら "メモ帳"。

問題が起きそうなポイント:
- IME が ON だと "notepad" がローマ字入力扱いされて失敗する
  → 念のため事前に半角英数モードにしておく
