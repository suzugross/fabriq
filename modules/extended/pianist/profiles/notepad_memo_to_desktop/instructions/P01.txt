P01: Run ダイアログを開く

Win+R を直接送る代わりに、Pianist は shell namespace GUID
`shell:::{2559a1f3-21d7-11d4-bdaf-00c04f60b9f0}` を ShellExecute
で叩き、Run ダイアログを表示します。Win+R を物理的に押したのと
同じ画面が表示されればこの Phase は成功です。

[Run Phase] を押すと:
  1. 既定の関連付けで Run ダイアログを開く
  2. ウィンドウタイトル "ファイル名を指定して実行" が現れるまで最大 5 秒待機
  3. 描画安定のため 300ms 待つ

期待される画面: 画面中央付近に小さな "ファイル名を指定して実行" ダイアログが表示される。

達成したら → の矢印で次の Phase へ。失敗したら [Phase Status...] で
Error をマークし、状況をメモに残してください。
