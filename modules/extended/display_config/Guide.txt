■ 概要
ディスプレイの解像度をレジストリ経由で設定します。
standard の resolution_api_config（即時反映）とは異なり、再起動後に反映されます。

■ 設定ファイル
[display_list.csv]
  Enabled     : 有効フラグ（1=実行, 0=スキップ）
  HardwareID  : ディスプレイのハードウェアID（AUTO=自動検出、空欄=対話選択）
  Width       : 横幅（ピクセル）
  Height      : 高さ（ピクセル）
  Description : 説明（表示用）
  Segment     : Segment フィルタ（省略可）

[記載例]
  1,AUTO,1920,1080,プライマリディスプレイ自動検出
  1,CMN14D40,1920,1080,内蔵14インチFHD
  1,LEN61CC,2560,1440,外部モニター QHD

■ HardwareID の指定方法
・AUTO : プライマリディスプレイを自動検出（下記「AUTO モードの動作」参照）
・具体的なID : デバイスマネージャーのモニターのハードウェアIDを指定
  （HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers\Configuration
   配下のサブキー名との前方一致で検索）
・空欄 : 実行時に対話形式で選択

■ AUTO モードの動作
HardwareID=AUTO 指定時は以下のロジックで対象を決定します。
  1) GraphicsDrivers\Configuration 配下のディスプレイ設定キーを列挙
  2) キーが 1 件のみ        → そのディスプレイを自動選択（プライマリ扱い）
  3) キーが 2 件以上        → 対話選択モードにフォールバック
                            （利用可能なディスプレイ一覧を提示し、番号で選択）
  4) キーが 0 件            → 対話選択モードにフォールバック
                            （実際には選択候補がないため対象なしで扱われる）

■ 前提条件
・管理者権限が必要です（スクリプト冒頭で Test-AdminPrivilege により検証）

■ AutoPilot
AutoPilot モードでは確認をスキップして CSV の設定を自動適用します。
ただし HardwareID が空欄または AUTO で複数ディスプレイ検出時は対話選択に
フォールバックするため、AutoPilot 運用時は HardwareID を具体的に指定することを
推奨します。

■ Post-Apply Verification
本モジュールは Post-Apply Verification を実装していません。
適用前に現在の PrimSurfSize.cx / PrimSurfSize.cy をレジストリから読み出して
冪等性判定は行いますが、設定反映には再起動が必要なため、適用直後の読み返し
検証は意味がなく省略しています。
New-BatchResult に -Verified は渡していないため、
実行履歴の Verified 列は空欄になります。

■ 注意事項
・変更の反映には再起動が必要です

■ 動作の流れ
1. display_list.csv を読み込み
2. 対象ディスプレイと現在の解像度を表示
3. 実行確認（Y/N）後、レジストリに書き込み
