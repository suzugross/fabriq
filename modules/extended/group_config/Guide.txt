■ 概要
ローカルグループにドメイングループ、ドメインユーザー、またはローカルユーザーを追加します。
本モジュールは 2 つのサブスクリプトで構成されます。
  - group_config.ps1  : メンバー追加（menu: Local Group Member Config）
  - group_remove.ps1  : メンバー除去（menu: Local Group Member Remove）
両者は同一の group_list.csv を共有し、group_remove は group_config の論理的逆操作です。

■ 設定ファイル
[group_list.csv]
  Enabled    : 有効フラグ（1=実行, 0=スキップ）
  LocalGroup : 追加先のローカルグループ名（例: Administrators）
  MemberType : メンバー種別（DomainGroup / DomainUser / LocalUser / CurrentUser）
  MemberName : 追加するメンバー名（CurrentUser の場合は空欄）
  Domain     : ドメイン名（LocalUser / CurrentUser の場合は空欄）
  Description : 説明（表示用）
  Segment    : Segment フィルタ（省略可）
               ※ Segment は kernel/common.ps1 の Import-ModuleCsv が
                 自動フィルタする共通機構。

[記載例]
  1,Administrators,DomainGroup,Client Administrators,city.osaka.example.jp,ドメイン管理者グループ,
  1,Remote Desktop Users,DomainGroup,RDP Users,city.osaka.example.jp,RDPユーザー,
  1,Users,LocalUser,testuser,,ローカルユーザー追加,
  1,Power Users,CurrentUser,,,現在のログインユーザーを追加,

■ MemberType について
  DomainGroup  : ドメイングループを追加（Domain\GroupName 形式）
  DomainUser   : ドメインユーザーを追加（Domain\UserName 形式）
  LocalUser    : ローカルユーザーを追加（UserName 形式）
  CurrentUser  : 現在ログインしているユーザーを自動検出して追加
                 ドメイン参加PCではドメインユーザーとして、
                 ローカルPCではローカルユーザーとして追加されます。
                 MemberName / Domain は空欄にしてください。

■ 前提条件
・管理者権限が必要です（Test-AdminPrivilege でスクリプト先頭にて明示チェック）
  - Add-LocalGroupMember / Get-LocalGroup / Get-LocalGroupMember に必須
・ドメインメンバーの追加にはドメインへの接続が必要です
・Get-CimInstance Win32_ComputerSystem が利用可能な Windows 環境であること
  （CurrentUser 解決のために使用）

■ AutoPilot
AutoPilot モードでは確認（Confirm-ModuleExecution）をスキップして
CSV の設定を自動適用します。

■ CurrentUser 解決の詳細
MemberType=CurrentUser の場合、Resolve-CurrentUser 関数が
以下の順序で実際のログオンユーザーを解決します。

  1. Get-CimInstance Win32_ComputerSystem の UserName プロパティ
     → "DOMAIN\username" 形式で対話セッションユーザーを取得
       （UAC 昇格時も昇格前のユーザーを正しく返します）
  2. 失敗または空の場合、フォールバックとして環境変数を参照:
     - $env:USERDOMAIN ≠ $env:COMPUTERNAME
       → "$env:USERDOMAIN\$env:USERNAME"（ドメインユーザー扱い）
     - それ以外
       → $env:USERNAME（ローカルユーザー扱い）

■ 冪等性（Test-LocalGroupMemberExists）
追加前に Get-LocalGroupMember でグループ内メンバーを列挙し、
以下のロジックで既存判定を行います。
  - MemberType=LocalUser: "$env:COMPUTERNAME\<MemberName>" または
    "<MemberName>" と完全一致するメンバーがあれば存在と判定
  - それ以外（DomainGroup / DomainUser / CurrentUser）:
    "*\<MemberName>" パターンで末尾一致するメンバーがあれば存在と判定

既存の場合は Show-Skip "Already a member" で $skipCount を増やし、
Add-LocalGroupMember は呼び出しません。

■ Post-Apply Verification
本モジュールは Post-Apply Verification を実装していません。
New-BatchResult に -Verified は渡していないため、実行履歴の
Verified 列は空欄になります。

[実装推奨メモ]
追加後に Test-LocalGroupMemberExists を再度呼び出し、期待メンバーが
すべて実在することを確認する Step 5.5 を追加すれば Verification を
実装可能です。冪等性チェック関数をそのまま再利用できる構造になっています。

■ 使用環境変数
- $env:USERDOMAIN    : CurrentUser 解決のフォールバック（ドメイン名）
- $env:USERNAME      : CurrentUser 解決のフォールバック（ユーザー名）
- $env:COMPUTERNAME  : LocalUser 判定 / ドメイン・ワークグループ判別
- $env:FABRIQ_SEGMENT : Segment フィルタ（Import-ModuleCsv が暗黙参照）

■ 動作の流れ
1. 管理者権限チェック（Test-AdminPrivilege）
2. group_list.csv を読み込み、追加対象を一覧表示
   （各行について Test-LocalGroupExists + Test-LocalGroupMemberExists で
    [Current]/[Change]/[ERROR] マーカーを表示）
3. 実行確認（Y/N）
4. 各メンバーをローカルグループに追加（既に存在する場合はスキップ）

■ メンバー除去（group_remove.ps1）
メンバー追加の論理的逆操作です。同じ group_list.csv の各行について、
メンバーをローカルグループから除去します。
  - 冪等性は反転: 既にメンバーでない場合は Show-Skip "Already not a member" でスキップ
  - グループ自体が存在しない場合も Skip（除去対象なし=目的達成、[No Group] 表示）
  - 現在のログオンユーザー自身を除去する行は警告を表示（dry-run と適用の両方）。
    特に Administrators からの自己除去は昇格セッションを失う恐れがあるため強く警告します。
    ※ 警告のみで実行はブロックしません（AutoPilot 下では確認なしで除去されます）。
  - 使用 cmdlet: Remove-LocalGroupMember
  - 動作の流れ:
    1. 管理者権限チェック（Test-AdminPrivilege）
    2. group_list.csv を読み込み、除去対象を一覧表示
       （[Remove]/[Absent]/[No Group] マーカーと自己除去警告を表示）
    3. 実行確認（Y/N）
    4. 各メンバーをローカルグループから除去（非メンバー/グループ不在はスキップ）
